# 🎒 CEK KELENGKAPAN SEBELUM PULANG KE POSKO KKN
Gunakan ceklis ini saat evaluasi sore di posko KKN untuk memastikan data sudah siap diinput ke database Supabase website:

- [ ] **Data Pak Dukuh:** Nama lengkap + Gelar + No WA + Foto Resmi + Kalimat Sambutan.
- [ ] **Data RW 16 (Pajangan):** Nama Ketua RW 16 + Nama Ketua RT 01 + Angka KK & Jiwa (L/P).
- [ ] **Data RW 17 (Wonosari):** Nama Ketua RW 17 + Nama Ketua RT 02 & RT 03 + Angka KK & Jiwa.
- [ ] **Data RW 18 (Rejosari):** Nama Ketua RW 18 + Nama Ketua RT 04 & RT 05 + Angka KK & Jiwa.
- [ ] **Data 3 Posyandu:** Jadwal penimbangan + No WA kader + Menu PMT + Data kasus stunting terpantau.
- [ ] **Data UMKM:** Minimal 3 produk dari 3 kampung lengkap dengan No WA penjual dan foto jelas.
- [ ] **Data Wisata & Budaya:** Minimal 2 titik spot pemandangan/edukasi + cerita tradisi Merti Dusun.

*(Jika semua kotak di atas sudah tercentang, tim IT KKN bisa langsung memasukkan data ke sistem web dalam waktu kurang dari 15 menit!)*
